# Electronic e-commerce store (DjangoREST Framework)

## Description
This is the back-end side of an ecommerce site. Registers data of the front-end with Axios / DjangoREST frameworrk,
connect to the front-end side for proper use.

## Technologies
- Python
- Django
- DjangoREST framework
- Axios
- Django admin


  ## How to run
  
### back-end
1. Clone this back-end repository:
   ```bash
   git clone (https://github.com/rmadilloman/demo-full-ecommerce)

2. Install dependencies:
    ```bash
   pip install -r requirements.txt

3. Run migrations
   ```bash
    python manage.py migrate

  4. Start the server
     ```bash
     python manage.py runserver

### Front-end

1. Clone the front-end repository:
    ```bash
   git clone https://github.com/rmadilloman/React-E-Commerce.git
    cd React-E-Commerce/ecommerce-app

2. Install dependencies:
   ```bash
   npm install

4. Start the development server:
   ```bash
   npm start
